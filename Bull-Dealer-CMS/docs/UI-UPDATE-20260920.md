# UI update — 20 September 2026

## Dealer website

The existing archive assets and component routes are retained. The latest changes restore the supplied reference appearance:

- Charcoal footer, yellow links, social icons, bottom BULL logo and current-year copyright.
- News cards with original images, calendar/date rows, yellow dividers and View More buttons. Three cards on desktop, one on mobile, pagination and automatic rotation, including the three-card desktop row.
- Customer testimonial carousel with a larger central portrait, smaller adjacent portraits, previous/next controls, pagination and four-second autoplay. Opening a video starts its YouTube embed; closing removes the iframe. Manual interaction stops testimonial autoplay, matching the original script.
- Equipment thumbnails update the large image on hover or keyboard focus and retain their configured manufacturer destinations. The mobile equipment carousel advances automatically and has selection dots.
- WhatsApp icon, configured contact URL and the original green hover/focus tooltip.

All content remains driven by the existing CMS. No existing section was removed. The original PHP and jQuery were translated into React components and effects; PHP is not executed in the browser. CSS remains in separate component files.
